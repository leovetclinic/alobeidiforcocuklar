# العبيدي لأناقة طفلك

المستودع الرسمي لمتجر **العبيدي لأناقة طفلك**.

## البنية الإنتاجية

- الواجهة والخادم: Cloudflare Workers
- قاعدة البيانات الدائمة: Cloudflare D1، بالربط `DB`
- صور المنتجات: Cloudflare R2، بالربط `BUCKET`
- الدومين: `alobeidiforcocuklar.win`

إعادة نشر الكود لا تعيد إنشاء قاعدة البيانات ولا تحذف الصور.

## البناء

يتطلب Node.js 22 أو أحدث.

```bash
npm ci
npm run build
```

يجب ضبط متغير البناء `CLOUDFLARE_D1_DATABASE_ID` بمعرّف قاعدة D1 الإنتاجية.

## أسرار التشغيل الأولي

تُحفظ بيانات دخول المدير الأولية كأسرار في Cloudflare، ولا توضع في GitHub:

- `ADMIN_BOOTSTRAP_USERNAME`
- `ADMIN_BOOTSTRAP_PASSWORD`

بعد إنشاء المدير لأول مرة يمكن تغيير اسم المستخدم وكلمة المرور من لوحة الإدارة.

## حماية البيانات

- لا تُرفع أسرار أو مفاتيح API إلى GitHub.
- الصور والمنتجات والمخزون والطلبات ليست جزءاً من ملفات النشر.
- تطبّق ترقيات D1 كتغييرات آمنة ولا تُستخدم أوامر حذف أو Reset في الإنتاج.
